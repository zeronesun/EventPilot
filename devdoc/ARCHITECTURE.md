## 核心架构组件说明

### 前端层
- **Vue 3 + TypeScript**: 现代化前端框架，提供类型安全和组件化开发
- **Vue Router**: 页面路由管理
- **Pinia**: 状态管理库，替代 Vuex
- **VueUse**: 实用工具库，提供常用组合式API
- **TailwindCSS**: 实用优先的CSS框架
- **Element Plus**: 企业级UI组件库
- **PWA 支持**: 渐进式Web应用，支持离线操作

### API 层
- **Django REST Framework**: RESTful API开发框架
- **JWT 认证**: 无状态认证机制，支持多端登录
- **中间件层**: 请求ID追踪、操作日志记录
- **异常处理**: 统一错误格式和错误码

### 业务逻辑层
- **用户模块**: 用户管理、权限控制
- **活动模块**: 活动项目管理、预算管理
- **任务模块**: 任务管理、依赖关系、看板视图
- **核验清单**: 清单模板、现场核验、报告生成
- **关联方档案**: 讲师、场地、供应商管理
- **知识库**: 问题记录、经验沉淀、智能推荐
- **复盘模块**: 活动复盘、问题分析、改进建议

### 数据层
- **PostgreSQL**: 关系型数据库，支持复杂查询和JSON数据
- **Redis 缓存**: 会话存储、热点数据缓存
- **文件存储**: 本地存储或对象存储

### 第三方服务
- **对象存储**: 阿里云OSS/腾讯云COS/AWS S3
- **微信集成**: 企业微信机器人通知
- **邮件服务**: 通知和提醒
- **短信服务**: 验证码和紧急通知

## 数据流
1. **前端请求** → API 层处理认证和路由
2. **API 层** → 业务逻辑层处理业务规则
3. **业务逻辑层** → 数据层持久化和查询
4. **数据层** → 业务逻辑层返回处理结果
5. **业务逻辑层** → API 层格式化响应
6. **API 层** → 前端层渲染界面

## 技术栈特点
- **前后端分离**: 独立部署，职责清晰
- **模块化设计**: 业务逻辑按功能模块划分
- **扩展性强**: 微服务化预留接口
- **安全性高**: 多层认证和权限控制
- **性能优化**: 缓存策略和数据库优化
