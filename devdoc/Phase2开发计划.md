# Phase 2 开发计划 - 核心功能完善

## 🎯 目标
Phase 2 的目标是将 EventPilot 从基础架构转变为功能完备的原型系统，实现完整的 CRUD 功能、实时通讯和文件上传能力。

## 📋 开发策略
基于用户的优先级选择：
1. **CRUD功能优先** - 先完善所有核心模块的增删改查
2. **WebSocket实时通讯** - 实现双向实时通信
3. **预签名URL文件上传** - 安全高效的文件存储

## 🏗️ 架构决策

### 技术栈确认
- **后端**: Django 5 + DRF (延续Phase 1)
- **前端**: Vue 3 + TypeScript + Vite (延续Phase 1)
- **实时通讯**: WebSocket (channels_django)
- **文件上传**: 预签名URL (S3兼容存储)
- **状态管理**: Pinia + React Query风格 (延续Phase 1)

### 核心模式
- **项目结构**: 功能优先 (feature-first)
- **API客户端**: Typed fetch wrapper (保持Phase 1)
- **认证**: JWT + 无感刷新机制
- **错误处理**: 类型化错误层级 + 全局处理器
- **日志**: 结构化JSON日志 + request ID传播
