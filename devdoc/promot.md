# 提示词：EventPilot 活动领航系统开发方案生成

## 一、任务模块

**核心任务**：作为一名专业的应用研发提示词工程师，请你根据以下提供的、经过深度梳理的业务需求与方案蓝图，生成一份专业、详尽、可立即用于指导开发的《EventPilot 活动领航系统 Web 应用开发方案》。

**输入与背景**：请严格依据下方提供的《活动全流程管理与进化系统》方案（以下简称“原方案”）进行输出。该系统被命名为 **EventPilot**，寓意“活动的智能领航员”，其首要定位是**高端活动承办团队内部使用的专业工作流引擎与知识中枢**，目标是实现活动交付的标准化、可控化与持续进化。

## 二、内容要求

请按照以下结构化框架，生成完整的开发方案文档。方案需逻辑严谨，语言精练，避免歧义。

### 第一部分：产品定义与核心价值

1. 

   **产品愿景**：成为活动承办团队的“数字大脑”，确保每次活动交付“精善尽美”，并让团队专业能力可持续积累和复用。

2. 

   **设计理念**：

   - 

     **以“活动项目”为中心**：聚合所有信息。

   - 

     **双轮驱动**：流程引擎（固化最佳实践） + 复盘引擎（沉淀经验教训）。

   - 

     **内外兼修**：对内是协同作战平台，对外是专业能力体现。

3. 

   **核心价值**：

   - 

     **对负责人**：全局视图掌控进度，沉淀标准化流程，通过数据驱动复盘优化。

   - 

     **对团队**：任务清晰透明，协作信息同步及时，减少失误。

   - 

     **对业务**：提升交付可靠性与客户满意度，构建专业服务壁垒。

### 第二部分：功能架构蓝图

系统需围绕“活动项目”全生命周期，构建以下四大中心模块。请详细描述每个模块的**核心子功能**及其要解决的**具体业务问题**。

- 

  **模块一：策划与启动中心**

  - 

    智能方案生成：基于模板一键生成《活动执行方案》。

  - 

    结构化预算看板：支持预算科目管理，实时对比“预估 vs 实际”，高亮预警。

  - 

    关联方档案库：为讲师、场地、供应商建立永久档案，记录合作历史与注意事项。

- 

  **模块二：执行与协同中心**

  - 

    可视化流程看板：支持“甘特图”与“看板视图”切换，管理多线任务（策划、嘉宾、物料、场地、宣传、现场、复盘）。

  - 

    结构化沟通任务：将关键沟通设为必须闭环的任务，需关联结论性文件或证据。

  - 

    物料与清单管理：将“心中清单”数字化、模板化，支持状态追踪。

- 

  **模块三：现场执行中心**

  - 

    移动端核验清单：基于确认需求生成可离线操作的现场检查清单，支持勾选、拍照、备注，并自动生成《核验报告》。

  - 

    简易现场工具：集成签到二维码、电子调查问卷发布功能。

  - 

    应急指南：支持配置每场活动的专属应急联系表与预案。

- 

  **模块四：复盘与进化中心**

  - 

    结构化复盘模板：引导从多维度（目标、流程、成本、客户反馈等）复盘，自动关联本次活动问题。

  - 

    问题与经验知识库：复盘“待改进项”自动转为知识条目并打标签。创建新活动时，系统智能推送相关历史问题。

  - 

    活动数据仪表盘：展示跨活动的核心指标趋势（如预算偏差率、任务完成率、问题发生率）。

### 第三部分：设计风格与交互要求

- 

  **设计原则**：专业、清晰、高效。界面以工具效率为核心，避免娱乐化设计。视觉上可考虑融入“舵轮”、“仪表盘”等“领航”元素。

- 

  **关键交互**：

  - 

    **微信整合**：支持将聊天记录中的结论截图上传并关联至具体任务；关键任务更新可配置微信提醒。

  - 

    **清单驱动**：现场核验等核心操作以“勾选完成”为主，追求极简交互。

  - 

    **全局搜索**：可快速搜索活动、联系人、文件、历史问题。

  - 

    **移动端适配**：“任务查看”与“现场核验”功能需对移动端浏览器有良好适配，支持添加到桌面。

### 第四部分：技术方案与实施路线

- 

  **技术栈建议**：

  - 

    **前端**：Vue 3 / React，实现单页面应用（SPA）体验，适配移动端。

  - 

    **后端**：Python (Django/Flask) 或 Node.js，建议优先考虑Django以利用其Admin快速搭建后台。

  - 

    **数据库**：PostgreSQL 或 MySQL。

  - 

    **部署**：支持容器化（Docker）部署，便于在主流云平台（如腾讯云、阿里云）部署。

- 

  **非功能性需求**：

  - 

    **权限控制**：灵活的RBAC（基于角色的访问控制），区分管理员、项目负责人、执行成员、只读观察者等角色，数据权限可控制到项目级。

  - 

    **数据安全**：关键业务数据加密存储，操作日志完整可追溯。

  - 

    **性能**：核心列表页加载时间 < 2秒，复杂操作响应时间 < 3秒。

- 

  **实施路线图（分三个阶段）**：

  1. 

     **Phase 1 - MVP (稳固交付，6-8周)**：实现“活动项目”数据模型、“数字化核验清单”、“多线任务看板”（看板视图）。**目标**：解决现场交付遗漏和信息不透明问题。

  2. 

     **Phase 2 - 协同增效 (8-10周)**：增加“关联方档案库”、“智能方案生成”、“结构化复盘报告”。**目标**：提升内外协作效率与专业形象。

  3. 

     **Phase 3 - 智能进化 (持续迭代)**：建设“知识库推送”、“数据趋势仪表盘”、深度“微信集成”。**目标**：形成数据驱动的优化闭环。
