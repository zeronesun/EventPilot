- 实现JWTAuthentication类 (符合fullstack-dev最佳实践)

- 配置JWT密钥和过期时间 (15分钟access, 7天refresh)
- 创建JWT端点:
  - `POST /api/auth/login/` - 用户登录
  - `POST /api/auth/refresh/` - 刷新token
  - `POST /api/auth/verify/` - 验证token
- 修复认证类循环导入问题

#### API端点路由
- 更新user模块URLs，添加JWT端点

## 🚀 启动指南

### 后端启动
```bash
# 启动Django开发服务器
python3 manage.py runserver --settings=config.settings.development

# 后端将在 http://localhost:8000 启动
```

### 前端启动
```bash
cd frontend
npm install  # 首次运行
npm run dev   # 启动开发服务器

# 前端将在 http://localhost:3000 启动
```

### 测试流程
1. 启动后端服务器
2. 启动前端服务器
3. 访问 http://localhost:3000/login
4. 使用admin用户登录
5. 验证数据加载和功能操作
