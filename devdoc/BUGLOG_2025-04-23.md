## Bug #4: Checklist API ViewSet 测试 404（路由未找到）

**发现时间:** 2025-04-23 23:11
**优先级:** P0 - 阻塞所有 Checklist ViewSet 测试

### 问题症状
12 个 Checklist ViewSet 测试全部返回 404：
- ChecklistTemplateTestCase (6 tests): test_create_checklist_template, test_create_template_invalid_data, test_duplicate_template, test_get_template_statistics, test_publish_template, test_update_template
- ChecklistInstanceTestCase (4 tests): test_create_instance_from_template, test_get_instance_progress, test_get_instance_report, test_update_instance_status
- ChecklistItemTestCase (2 tests): test_add_attachment, test_update_item_status

所有测试错误信息：
```
WARNING Not Found: /api/checklists/templates/
WARNING Not Found: /api/checklists/instances/
...
AssertionError: 404 != 201 (or 200)
```

### 根本原因
URL 路由注册存在问题。虽然 python debug_patterns.py 显示 checklists URL resolver 已注册：
```
<URLResolver <module 'apps.checklists.api.urls'> (checklists:checklists) 'api/'>
```
但实际请求时无法解析到底层 ViewSet。

### 影响测试数量
12 个 Checklist ViewSet 集成测试

### 诊断状态
需要检查：
1. ViewSet 的 basename 配置是否正确
2. router.register 的路径映射
3. pytest 测试客户端的 URL 解析机制

### 解决计划
1. 检查 apps/checklists/api/urls.py 的 router 配置
2. 验证 Viewset 的 basename 与路由注册是否匹配
3. 可能需要使用 Django 的 reverse() 而非硬编码 URL
