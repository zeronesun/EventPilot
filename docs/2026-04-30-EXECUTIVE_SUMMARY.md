## 1. 项目定位与概况

### 1.1 项目基本信息

EventPilot是一个**企业级活动管理系统**，支持多用户协作、实时任务管理、文件分享、细粒度权限控制和WebSocket实时通信。

**核心技术栈**:
- 后端: Django 4.2 + DRF + Channels + PostgreSQL + Redis  
- 前端: Vue 3 + Vite + Pinia + Element Plus + TypeScript  
- 安全: PBKDF2 + JWT + HMAC-SHA256 + RBAC

### 1.2 项目架构特点

- **前后端分离**: RESTful API + WebSocket双向通信
- **企业级安全**: 多层安全防护
- **细粒度权限**: 5级角色 + 15+ 权限
- **实时协作**: WebSocket看板拖拽 + 乐观更新
- **高度可扩展**: 清晰的模块化架构
